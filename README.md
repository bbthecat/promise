# สัญญาใจ · promise

เว็บแบบฟอร์มสัญญาใจประจำกลุ่ม จากโครงงาน “การศึกษาสภาพปัญหาความขัดแย้งในการทำงานกลุ่มและการพัฒนาแบบฟอร์มสัญญาใจเพื่อลดความขัดแย้ง”
รายวิชา GE362785 การคิดเชิงสร้างสรรค์และการแก้ปัญหา มหาวิทยาลัยขอนแก่น

- **สัญญาใจ.doc** ใช้แบ่งหน้าที่ กำหนดส่ง เขียนบทลงโทษและข้อตกลง ให้ทุกคนลงชื่อ แล้วปิดผนึก จากนั้นติดตามสถานะงาน พิมพ์ / PDF หรือบันทึกเป็นรูป
- **แบบสอบถาม** สำรวจปัญหา สรุปเป็นความถี่และร้อยละ และส่งข้อตกลงที่เพื่อนเสนอเข้าไปในสัญญาได้
- **แบบประเมินผล** ใช้มาตรวัด 5 ระดับ คำนวณค่าเฉลี่ย (x̄) และส่วนเบี่ยงเบนมาตรฐาน (S.D.) ให้
- **คัดลอกลิงก์** ข้อมูลสัญญาทั้งหมดอยู่ในลิงก์ ส่งให้เพื่อนเปิดได้โดยไม่ต้องมีฐานข้อมูล

ข้อมูลทั้งหมดเก็บใน localStorage ของเบราว์เซอร์

## พัฒนา

```bash
npm install
npm run dev
npm run build   # ได้ไฟล์ใน dist/
```

Deploy บน Vercel: import repo นี้ เลือก framework เป็น Vite แล้วใช้ค่าเริ่มต้นได้เลย
